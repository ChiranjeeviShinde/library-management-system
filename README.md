# 📚 Library Management System

A modern **Library Management System** built using **C++ (OOP)** and a **web-based UI (HTML/CSS/JS)**.  
It allows managing books, issuing/returning, searching, and tracking availability in a clean interface.

---

## Features

-  Add new books
-  Issue books to students
-  Return books
-  Search by ID, title, or author
-  View total / available / issued counts
-  Persistent storage using file handling (`library.txt`)
-  Input validation (duplicate ID, invalid operations)
-  Modern UI with dashboard + catalogue view
